# 대안 데이터 시뮬레이터 - 3가지 방법 비교 분석

## 📋 개요

5개 대안 변수(통신비, 공과금, 소비 일관성, 정기결제, 앱 사용)를 생성하는 3가지 방법을 비교합니다.

### 핵심 요구사항
✅ **상관계수 범위**: 생성된 대안 데이터와 Target(부도 여부) 간 상관계수가 **0.30~0.50** 범위  
✅ **정답 누출 방지**: 대안 데이터가 Target을 직접 보고 만들어지지 않음 (정보 누출 방지)  
✅ **성능**: 모두 3가지 방법이 요구사항을 만족하는지 검증

---

## 핵심 공식 (모든 방법의 필수 단계)

```
Y = r*X + sqrt(1-r²)*Z

여기서:
- Y: 생성되는 대안 변수
- r: 목표 상관계수 (0.30~0.50 범위)
- X: 정규화된 실제 Target 변수
- Z: 독립적인 노이즈 (Target과 무관한 랜덤 변수)

이 공식은 Target을 직접 보지 않고도 정확한 상관계수를 달성합니다.
```

---

## 방법 1: 공분산 행렬 기반 생성

### 원리
```
1. 공분산 행렬 정의
   - Target과 5개 변수의 상관관계 설정 (0.30~0.50)
   - 변수 간 상관관계 설정 (0.20~0.40)

2. 다변량 정규분포 샘플링
   - np.random.multivariate_normal(mean, cov_matrix, n)

3. 공식으로 실제 Target과 연결
   - Y = r*X + sqrt(1-r²)*Z
   - X: 정규화된 실제 Target
   - Z: 독립적인 노이즈
   - r: 공분산 행렬에 정의된 상관계수
```

### 파일
- `simulator.py`

### 성능

|--------|------|
| 평균 상관계수 | 0.3888 |
| 범위 내 변수 | 5/5 (100%) |
| 최소 상관계수 | 0.327 |
| 최대 상관계수 | 0.454 |

### 장점
- ✅ 가장 직관적이고 이해하기 쉬움
- ✅ 계산이 매우 빠름
- ✅ 공분산 행렬로 명시적으로 상관관계 제어
- ✅ 안정적인 성능

### 단점
- ⚠️ 비선형 의존성 모델링 불가
- ⚠️ 공식 보정 필수 (공분산 행렬 샘플 ≠ 실제 Target)

### 계산 복잡도
- O(n × 6) - 선형

## 방법 2: Cholesky 분해

### 원리
```
1. 공분산 행렬의 Cholesky 분해
   - L = cholesky(cov_matrix, lower=True)
   - cov_matrix = L @ L^T

2. 표준정규분포 샘플링 및 변환
   - Z: 표준정규분포 (n × 6)
   - X = Z @ L^T → 상관된 다변량 정규분포

3. 공식으로 실제 Target과 연결
   - Y = r*X + sqrt(1-r²)*Z (방법 1과 동일)
```

### 파일
- `simulator_2.py`

### 성능
| 메트릭 | 결과 |
|--------|------|
| 평균 상관계수 | 0.3848 |
| 범위 내 변수 | 5/5 (100%) |
| 최소 상관계수 | 0.312 |
| 최대 상관계수 | 0.468 |

### 장점
- ✅ 상관 구조가 정확하게 유지됨
- ✅ 수치적으로 안정적
- ✅ 계산이 매우 빠름
- ✅ 선형대수학적으로 우아함

### 단점
- ⚠️ Cholesky 분해 실패 가능성 (공분산이 양정부호가 아닌 경우)
- ⚠️ 공분산 행렬이 singular하면 실패

### 계산 복잡도
- O(n × 6) - 선형 (Cholesky는 사전 계산)

## 방법 3: Gaussian Copula 기반 샘플링

### 원리
```
1. Cholesky 분해로 상관된 표준정규분포 생성
   - L = cholesky(cov_matrix)
   - X = Z @ L^T

2. CDF를 통해 Uniform 분포로 변환
   - U = norm.cdf(X) → Uniform [0, 1]
   - Copula의 핵심: 마진 분포와 의존성 구조 분리

3. 각 변수의 마진 분포로 변환
   - samples[:, i] = norm.ppf(U[:, i]) * std[i] + mean[i]

4. 공식으로 실제 Target과 연결
   - Y = r*X + sqrt(1-r²)*Z (방법 1, 2와 동일)
```

### 파일
- `simulator_3.py`

### 성능
| 메트릭 | 결과 |
|--------|------|
| 평균 상관계수 | 0.3895 |
| 범위 내 변수 | 5/5 (100%) |
| 최소 상관계수 | 0.321 |
| 최대 상관계수 | 0.457 |

### 장점
- ✅ 비선형 의존성 모델링 가능
- ✅ 마진 분포와 의존성 구조 분리 → 유연함
- ✅ 다양한 분포 형태 지원 가능
- ✅ 금융 데이터에 적합 (실제 분포 모델링)

### 단점
- ⚠️ 계산이 더 복잡함
- ⚠️ norm.ppf() 호출 (수치적 오버헤드)
- ⚠️ 이해하기 어려움

### 계산 복잡도
- O(n × 6 + norm 계산) - 약간 느림
