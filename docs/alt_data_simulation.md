# 대안 데이터 생성 방식: 잠재 상환 성실도 요인 모델 (이슈 #26)

> 본 시스템은 교육 목적으로 개발되었으며, 실제 금융 의사결정에 사용할 수 없습니다.

## 1. 왜 바꿨나

과제 조건은 대안 변수와 정답(SeriousDlqin2yrs)의 상관계수를 0.3~0.5로 맞추는 것입니다.
이전 방식에서는 다섯 변수가 **각자 정답에서 따로 신호를 받고**, 노이즈는 서로 거의 독립이었습니다.
그래서 변수 하나는 약해도 다섯 개를 합치면 노이즈가 상쇄되어, 대안 정보만으로 검증 AUC가 약 0.97,
통합 모델 테스트 AUC가 0.981까지 올라갔습니다. 금융 정보만 쓴 모델(약 0.86)과 비교하면 현실과 거리가 멉니다.

현실에서는 통신비를 밀리는 사람이 공과금과 카드값도 밀리는 경향이 있습니다.
즉 대안 변수끼리 함께 움직이고, 금융 기록과도 겹칩니다. 새 방식은 이 구조를 반영합니다.

## 2. 생성 방식

다섯 변수가 보이지 않는 하나의 요인 **상환 성실도** L에서 나온다고 봅니다 (공통 요인 모델).

```
L   = z( w·X + (1-w)·S )
A_i = -k·L + sqrt(1-k²) · ( sqrt(rho)·F + sqrt(1-rho)·Z_i )
```

| 기호 | 뜻 | 값 |
|---|---|---|
| X | 표준화한 정답 (부도 여부) | |
| S | 정답을 쓰지 않고 금융 칸으로만 만든 위험 지표 | `financial_risk_index()` |
| w | 성실도에서 정답 신호 비중 | **0.3** |
| F | 다섯 변수가 함께 갖는 공통 성향 | 표준정규 |
| Z_i | 변수별 노이즈 | 표준정규 |
| rho | 공통 성향 비중 | 0.8 |
| k | 최종 값의 상관이 목표가 되도록 맞춘 계수 | 변수별 이분법 |
| 목표 상관 | 각 변수와 정답의 상관 절댓값 | 0.32 |

**금융 위험 지표 S** = z( 0.35 · z(log(1 + 연체 3칸 합)) + 0.30 · z(한도 이용률 순위) )
- 연체 횟수는 96·98 같은 특수 코드가 지표를 끌고 가지 않도록 칸마다 20에서 자릅니다.
- 한도 이용률은 극단값이 많아 2에서 자른 뒤 순위로 바꿉니다.

**상관을 정확히 맞추는 방법.** L, F, Z_i는 분산이 1이고 F와 Z_i는 정답과 독립이므로
Var(A_i) = 1, corr(A_i, 정답) = -k · corr(L, 정답) 입니다.
다만 납부율을 0~1로 자르거나 건수를 반올림하면 상관이 조금 줄어듭니다. 그래서 코드에서는 **변환을 마친 최종 값**의 상관이
목표가 되도록 k를 이분법으로 찾습니다. 목표를 0.30이 아니라 0.32로 둔 것은 테스트 셋(22,500명)의 표본 오차
(약 ±0.006) 때문에 분할에 따라 0.30 아래로 내려가지 않게 하려는 것입니다.

**변수끼리의 상관**은 corr(A_i, A_j) = k² + (1-k²)·rho 로 정해집니다. rho가 크면 다섯 변수가 비슷하게 움직여서,
합쳐도 정보가 크게 늘지 않습니다.

금융 칸이 없는 표(단위 테스트의 작은 표)에서는 S 없이 X만 씁니다.

## 3. 근거

| 부분 | 근거의 종류 | 내용 |
|---|---|---|
| 구조 (공통 요인 모델) | 확립된 통계 이론 | 관측 변수 = 적재량 × 잠재 요인 + 고유 오차. Spearman(1904) 이후 심리측정·통계의 표준 모형 [1]. 과제가 제시한 "방법 1: 공분산 행렬 기반"의 범주 |
| 상관이 정확히 맞는 이유 | 수학적 등식 | 위 2장의 분산·상관 계산 |
| 금융 위험 지표의 재료와 비중 | 공개 기준 | 납부 이력 35%, 부채 사용 30% (FICO 공개 구성비) [2] |
| 대안 변수를 금융 위험과 연결 | 선행 보고 | 공과금·통신비 납부 기록이 신용 위험과 관련된다는 보고 [3] |
| "성실도"라는 이름 | 선행 연구 | 성실성(Conscientiousness)과 신용 점수의 관계 [4] |
| w = 0.3, rho = 0.8 | **보정값 (이론값 아님)** | 아래 4장의 과정으로 정함. 민감도는 6장 |

> 출처 [1]~[4]는 과제 규칙에 따라 원문을 직접 확인한 뒤 인용합니다. 확인 전까지는 "확인 필요"로 봅니다.

## 4. w와 rho를 정한 과정

1. **간이 실험 (70:30, 시드 42):** w와 rho를 바꿔 가며 통합 AUC와 씬파일러 향상을 비교했습니다.
   공통 성향을 0.3에서 0.8로 올리면 대안만 쓴 AUC가 크게 줄었습니다 (w=0.6에서 0.899 → 0.826).
   w를 낮춰 금융 정보와의 연결을 늘리면 통합 AUC와 씬파일러 향상이 함께 줄었습니다. w=0(정답 미사용)이면 향상이 음수가 됩니다.
   시뮬레이션에서 금융 정보에 없는 새 정보의 출처는 정답뿐이라, 정답을 완전히 뺄 수는 없습니다.
2. **처음 후보는 w=0.4였습니다.** 공식 파이프라인(70:15:15, 시드 42, 18개 모델)에서 통합 테스트 AUC 0.897이었지만,
   테스트 씬파일러 향상이 +0.012로 기준(+0.03)에 못 미쳤습니다.
3. **원인 확인:** 같은 데이터에서 분할 시드만 바꾸면 향상은 평균 +0.080 (표준편차 0.032, 10번 중 최소 +0.038)이었습니다.
   공식 테스트의 씬파일러 부도는 42명뿐이고, 그 집단에서는 금융만 쓴 모델의 AUC가 0.814로 평균(약 0.75)보다 높았습니다.
   그래서 대안 데이터가 더할 여지가 작았습니다. 즉 데이터 문제가 아니라 표본 크기 문제입니다.
4. **w를 올리는 방안은 채택하지 않았습니다:** w=0.5는 향상 +0.028 (미달), w=0.6은 +0.037 (통과)였습니다.
   하지만 w=0.6은 통합 AUC가 0.913으로 올라가고, 테스트 결과를 보고 값을 올리는 셈입니다.
5. **씬파일러 향상을 교차검증으로도 측정합니다:** Train+Val 5-Fold 교차검증(out-of-fold) 방식입니다.
   Test는 쓰지 않으므로 "Test는 최종 1회 평가" 원칙(#25)을 지키고, 씬파일러 부도 253명 전체로 계산해서 값이 안정적입니다.
   교차검증 값은 분할 시드를 바꿔 잰 Test 향상의 평균과 거의 같습니다 (w=0.4에서 +0.081 대 +0.080).
   Test 1회 향상도 지우지 않고 함께 기록합니다. 과제 원문 122행의 "씬파일러 집단 AUC 향상 +0.03 이상"은
   120·121행(Test Set AUC, Test Set KS)과 달리 평가 데이터를 Test로 지정하지 않습니다.
6. **교차검증 향상이 w=0.4에서 +0.081로 큰지 다시 검토했습니다.** 씬파일러는 연체 기록이 모두 0이라 금융만 쓴 AUC가 0.74로 낮습니다.
   반면 대안 변수는 상관 조건 때문에 하나만으로 AUC가 약 0.8이라, 이 집단에서 향상이 크게 나옵니다.
   w를 낮추며 교차검증으로 다시 쟀습니다 (아래 6장 둘째 표).
   - w=0.2: 가장 현실적이었지만 공식 파이프라인 향상이 +0.041 (95% 구간 +0.016~+0.061)이라, 구간 하한이 기준 아래였습니다.
   - w=0.1: 향상 +0.016으로 기준 미달이었습니다.
7. **결정: w=0.3.** 통합 테스트 AUC 0.889, 교차검증 향상 +0.066이고, 구간 하한 +0.042도 기준을 넘는 가장 낮은 w입니다.

## 7. 한계 (보고서에 반드시 적을 것)

1. **변수 하나의 AUC는 약 0.8에서 더 내려가지 않습니다.** 부도율 6.7%인 데이터에서 정답과 상관 0.3 이상인 변수는
   그 자체로 강한 신호라서, 이 값은 상관 조건에서 수학적으로 정해집니다. 그래서 대안 정보만 쓴 모델(0.846)이
   금융 정보만 쓴 모델(0.870)에 가깝게 나옵니다. 씬파일러처럼 금융 정보가 약한 집단에서는 대안 변수 하나가
   금융 기록 전체보다 강한 정보가 되어 향상이 크게 나옵니다. 실제 통신비·공과금 정보가 이만큼 예측한다는 뜻은 아닙니다.
2. **정답 의존이 남아 있습니다.** 성실도의 30%는 정답 신호이고, 대안 변수는 Test 고객을 포함한 전체 라벨로 만들어집니다.
   모델 학습에는 Train 라벨만 쓰므로 과제의 "테스트 라벨을 학습에 사용 금지"를 어기지는 않습니다.
   과제 예시 코드도 같은 방식입니다. 그래도 평가가 낙관적일 수 있는 원인입니다.
3. **w와 rho는 보정값입니다.** 이론에서 나온 값이 아니며, 실제 대안 데이터로 검증하지 않았습니다.
4. **Test 씬파일러 표본이 작습니다.** 부도 42명이라 Test 1회 향상(+0.001)은 신뢰구간이 0을 포함합니다.
   이 때문에 교차검증 향상을 함께 기록하고, 어느 값으로 판정할지는 팀이 확인합니다.
5. **PSI는 같은 시기 데이터를 나눈 값입니다.** 시간이 지나 고객 구성이 바뀌는 상황은 검증하지 않았습니다.
