# 대시보드 입력 항목 명세서

대시보드에서 신용 평가 모델에 입력할 수 있는 모든 항목을 정의합니다.

---

## 📋 개요

**총 18개 입력 항목**
- 원본 금융 데이터: 11개
- 인구통계 데이터: 2개 (성별, 연령대)
- 대안 데이터 (Alternative Data): 5개

> **참고**: `is_thin_filer` (씬파일러 판정 여부)는 **모델이 자동 계산**하므로 대시보드에서 입력받지 않습니다.

---

## 1️⃣ 인구통계 데이터 (2개)

### 1.1 Gender (성별)
- **설명**: 고객의 성별
- **데이터 타입**: Integer (정수)
- **값**:
  - 0 = 여성 (Female)
  - 1 = 남성 (Male)
- **단위**: 카테고리
- **예시**: 0 (여성), 1 (남성)
- **비고**: 대시보드 표시 용도. 모델 학습에는 포함되지 않음

### 1.2 AgeGroup (연령대)
- **설명**: 고객의 연령대
- **데이터 타입**: Integer (정수)
- **값**:
  - 0 = 20~29세
  - 1 = 30~39세
  - 2 = 40~49세
  - 3 = 50~59세
  - 4 = 60세 이상
- **단위**: 카테고리
- **예시**: 2 (40대), 3 (50대)
- **비고**: Age 컬럼에서 자동 계산됨. 대시보드에서 선택할 때 참조용으로 사용 가능

---

## 2️⃣ 원본 금융 데이터 (11개)

### 1.1 RevolvingUtilizationOfUnsecuredLines
- **설명**: 무보증 신용 한도에 대한 이용률
- **데이터 타입**: Float (소수점)
- **범위**: 0.0 ~ 28.0
- **단위**: 백분율 (%)
- **예시**: 0.5 (50% 이용), 1.2 (120% 이용)
- **비고**: 신용카드, 개인대출 등의 이용률을 나타냅니다

### 1.2 Age
- **설명**: 고객 나이
- **데이터 타입**: Integer (정수)
- **범위**: 21 ~ 100
- **단위**: 세 (년)
- **예시**: 35, 48, 67
- **비고**: 21세 이상의 성인 고객만 대상

### 1.3 NumberOfTime30-59DaysPastDueNotWorse
- **설명**: 30~59일 연체 경험 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 98
- **단위**: 횟수
- **예시**: 0 (연체 없음), 2 (2회 연체)
- **비고**: 최악의 상황이 아닌 경우만 카운트

### 1.4 DebtRatio
- **설명**: 월간 채무의 총 월수입에 대한 비율
- **데이터 타입**: Float
- **범위**: 0.0 ~ 332.0
- **단위**: 백분율 (%)
- **예시**: 0.4 (월수입의 40%), 1.5 (월수입의 150%)
- **비고**: 100% 이상이면 소비가 수입을 초과함을 의미

### 1.5 MonthlyIncome
- **설명**: 월간 소득
- **데이터 타입**: Float
- **범위**: 0.0 ~ 3,008,750.0
- **단위**: 원
- **예시**: 2,000,000 (200만 원), 5,500,000 (550만 원)
- **비고**: 결측치 발생률 19.82% (중앙값으로 보정됨)

### 1.6 NumberOfOpenCreditLinesAndLoans
- **설명**: 개설된 신용 계좌의 수
- **데이터 타입**: Integer
- **범위**: 0 ~ 58
- **단위**: 개
- **예시**: 1, 5, 12
- **비고**: 신용 이력의 다양성을 나타냄. 이 값이 2 미만이면 씬파일러 판정 기준

### 1.7 NumberOfTimes90DaysLate
- **설명**: 90일 이상 연체 경험 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 98
- **단위**: 횟수
- **예시**: 0, 1, 3
- **비고**: 심각한 연체 기록

### 1.8 NumberRealEstateLoansOrLines
- **설명**: 부동산 관련 신용 계좌의 수
- **데이터 타입**: Integer
- **범위**: 0 ~ 54
- **단위**: 개
- **예시**: 0 (없음), 1, 2
- **비고**: 주택담보대출, 주택담보 신용 한도 등

### 1.9 NumberOfTime60-89DaysPastDueNotWorse
- **설명**: 60~89일 연체 경험 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 98
- **단위**: 횟수
- **예시**: 0, 1
- **비고**: 30~59일 범위보다 심각한 연체

### 1.10 NumberOfDependents
- **설명**: 부양 인원 수
- **데이터 타입**: Float
- **범위**: 0.0 ~ 20.0
- **단위**: 명
- **예시**: 0 (부양 없음), 1, 2, 3
- **비고**: 결측치 발생률 2.62% (중앙값으로 보정됨)

## 3️⃣ 대안 데이터 (Alternative Data) - 5개

> **설명**: 금융 기록이 부족한 고객(씬파일러)의 신용도 평가를 위해 생성된 변수들입니다.
> 통신사 결제, 공과금, 모바일 앱 사용 패턴 등의 대안 데이터를 활용합니다.

### 2.1 TelecomPaymentRate
- **설명**: 통신사 납부 이행률
- **데이터 타입**: Float
- **범위**: 0.0 ~ 1.0
- **단위**: 비율 (0 = 0%, 1 = 100%)
- **예시**: 0.95 (95% 이행), 0.75 (75% 이행)
- **비고**: 휴대폰, 인터넷 등 정기 납부 기록

### 2.2 UtilityPaymentRate
- **설명**: 공과금(전기, 가스, 수도) 납부 이행률
- **데이터 타입**: Float
- **범위**: 0.0 ~ 1.0
- **단위**: 비율
- **예시**: 0.98 (98% 이행), 0.85 (85% 이행)
- **비고**: 정기 고정비 납부 규칙성

### 2.3 SpendingConsistency
- **설명**: 소비 패턴의 일관성 점수
- **데이터 타입**: Float
- **범위**: 0.0 ~ 100.0
- **단위**: 점수
- **예시**: 75.5, 82.0, 65.3
- **비고**: 월별 소비 변동성이 낮을수록 높은 점수 (높을수록 좋음)

### 2.4 RegularPaymentCount
- **설명**: 정기적인 거래(결제) 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 20
- **단위**: 횟수/월
- **예시**: 5, 8, 12
- **비고**: 정기적인 소비 활동의 빈도

### 2.5 AppLoginFrequency
- **설명**: 금융 앱/서비스 접속 빈도
- **데이터 타입**: Integer
- **범위**: 0 ~ 35
- **단위**: 횟수/월
- **예시**: 10, 15, 20
- **비고**: 금융 서비스 이용 활동성

---

## 4️⃣ 자동 계산 변수 (입력 불가)

### 4.1 is_thin_filer (씬파일러 판정)
- **설명**: 금융 기록 부족 고객 여부
- **데이터 타입**: Binary (0 또는 1)
- **계산 기준**:
  - 기준 1: 금융 연체 관련 컬럼 2개 이상 결측
  - 기준 2: 또는 신용카드 거래 계좌 수 < 2개
  - (두 기준 중 하나라도 만족하면 씬파일러)
- **결과**: 0 = 일반 고객, 1 = 씬파일러
- **비고**: 모델이 자동으로 판정하므로 대시보드에서 입력하지 않음

---

## 5️⃣ 모델 예측 대상

### 5.1 SeriousDlqin2yrs (목표 변수)
- **설명**: 2년 내 90일 이상 연체 여부 (신용도)
- **데이터 타입**: Binary
- **값**: 0 = 연체 없음 (정상), 1 = 90일 이상 연체 (부도)
- **클래스 분포**: 0 (93.32%), 1 (6.68%)
- **비고**: 모델의 예측 대상이므로 대시보드에서 입력하지 않음

---

## 6️⃣ 데이터 입력 시 유의사항

### 필수 확인 사항
1. **숫자형 입력**: 모든 값은 지정된 범위 내 유효한 숫자여야 합니다
2. **결측치 처리**: 
   - MonthlyIncome, NumberOfDependents는 선택적 입력 가능
   - 입력되지 않으면 전체 데이터의 중앙값으로 자동 보정됨
3. **스케일링**: 대시보드에서 입력한 원본 값은 모델 내부에서 자동으로 표준화됨

### 입력 순서 권장사항
1. 기본 정보: Age, NumberOfDependents
2. 신용 이력: RevolvingUtilizationOfUnsecuredLines, DebtRatio, MonthlyIncome
3. 연체 기록: 30~59일, 60~89일, 90일 이상 연체 횟수
4. 신용 계좌: NumberOfOpenCreditLinesAndLoans, NumberRealEstateLoansOrLines
5. 대안 데이터: TelecomPaymentRate, UtilityPaymentRate, SpendingConsistency, RegularPaymentCount, AppLoginFrequency
