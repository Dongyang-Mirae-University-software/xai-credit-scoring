# 신용평가 모델 - 입력 변수 명세서

신용 거절 위험도 평가 시스템에서 사용되는 모든 입력 변수를 정의합니다.
이 문서는 **팀원, API 개발자, 그리고 외부 사용자**가 각 변수의 의미를 명확히 이해할 수 있도록 작성되었습니다.

---

## 📋 개요

**총 18개 입력 항목**
- 원본 금융 데이터: 11개
- 인구통계 데이터: 2개 (성별, 연령대)
- 대안 데이터 (Alternative Data): 5개

> **참고**: `is_thin_filer` (씬파일러 판정 여부)는 **모델이 자동 계산**하므로 대시보드에서 입력받지 않습니다.

---

## 1️⃣ 인구통계 데이터 (2개)

### 1.1 Gender (성별)
- **설명**: 고객의 성별
- **데이터 타입**: Integer (정수)
- **값**:
  - 0 = 여성 (Female)
  - 1 = 남성 (Male)
- **단위**: 카테고리
- **예시**: 0 (여성), 1 (남성)
- **비고**: 대시보드 표시 용도. 모델 학습에는 포함되지 않음

### 1.2 AgeGroup (연령대)
- **설명**: 고객의 연령대
- **데이터 타입**: Integer (정수)
- **값**:
  - 0 = 20~29세
  - 1 = 30~39세
  - 2 = 40~49세
  - 3 = 50~59세
  - 4 = 60세 이상
- **단위**: 카테고리
- **예시**: 2 (40대), 3 (50대)
- **비고**: Age 컬럼에서 자동 계산됨. 대시보드에서 선택할 때 참조용으로 사용 가능

## 2️⃣ 원본 금융 데이터 (11개)

### 2.1 RevolvingUtilizationOfUnsecuredLines
- **설명**: 무보증 신용 한도에 대한 이용률
- **데이터 타입**: Float (소수점)
- **범위**: 0.0 ~ 28.0
- **단위**: 백분율 (%)
- **예시**: 0.5 (50% 이용), 1.2 (120% 이용)
- **비고**: 신용카드, 개인대출 등의 이용률을 나타냅니다

### 2.2 Age (나이)
- **설명**: 고객의 나이
- **데이터 타입**: Integer (정수)
- **범위**: 21 ~ 100세
- **단위**: 세 (년)
- **예시**: 35, 48, 67
- **비고**: 21세 이상의 성인 고객만 대상

### 2.3 NumberOfTime30-59DaysPastDueNotWorse (30~59일 연체 횟수)
- **설명**: 30~59일 미만 연체 경험 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 98회
- **단위**: 횟수
- **예시**: 0 (연체 없음), 2 (2회 연체)
- **비고**: 최악의 상황이 아닌 경우만 카운트 (의무 불이행은 포함 안 함)

### 2.4 DebtRatio (부채비율)
- **설명**: 월간 채무(분할 상환)의 총 월수입에 대한 비율
- **데이터 타입**: Float
- **범위**: 0.0 ~ 332.0
- **단위**: 백분율 (%)
- **예시**: 0.4 (월수입의 40%), 1.5 (월수입의 150%)
- **비고**: 100% 이상이면 소비가 수입을 초과함을 의미

### 2.5 MonthlyIncome (월간 소득)
- **설명**: 고객의 월간 총 소득
- **데이터 타입**: Float
- **범위**: 0.0 ~ 3,008,750.0
- **단위**: 원 (KRW)
- **예시**: 2,000,000 (200만 원), 5,500,000 (550만 원)
- **비고**: 결측치 발생률 19.82% (중앙값으로 자동 보정됨)

### 2.6 NumberOfOpenCreditLinesAndLoans (개설된 신용 계좌 수)
- **설명**: 현재 개설된 신용선과 대출 계좌의 수
- **데이터 타입**: Integer
- **범위**: 0 ~ 58개
- **단위**: 개
- **예시**: 1, 5, 12
- **비고**: 신용 이력의 다양성을 나타냄. **씬파일러(Thin-filer) 판정 기준 2의 조건 중 하나** (1개 이하, 4.1 참고)

### 2.7 NumberOfTimes90DaysLate (90일 이상 연체 횟수)
- **설명**: 90일 이상 연체 경험 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 98회
- **단위**: 횟수
- **예시**: 0, 1, 3
- **비고**: 심각한 연체 기록 (신용도에 큰 영향)

### 2.8 NumberRealEstateLoansOrLines (부동산 신용 계좌 수)
- **설명**: 부동산 관련 신용 계좌의 수
- **데이터 타입**: Integer
- **범위**: 0 ~ 54개
- **단위**: 개
- **예시**: 0 (없음), 1, 2
- **비고**: 주택담보대출, 주택담보 신용 한도 등

### 2.9 NumberOfTime60-89DaysPastDueNotWorse (60~89일 연체 횟수)
- **설명**: 60~89일 연체 경험 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 98회
- **단위**: 횟수
- **예시**: 0, 1
- **비고**: 30~59일 범위보다 심각한 연체

### 2.10 NumberOfDependents (부양 인원 수)
- **설명**: 고객이 부양하는 가족 구성원 수
- **데이터 타입**: Float
- **범위**: 0.0 ~ 20.0명
- **단위**: 명
- **예시**: 0 (부양 없음), 1, 2, 3
- **비고**: 결측치 발생률 2.62% (중앙값으로 자동 보정됨)

## 3️⃣ 대안 데이터 (Alternative Data) - 5개

> **설명**: 금융 기록이 부족한 씬파일러(Thin-filer) 고객을 평가하기 위한 변수입니다.
> **통신사 결제, 공과금 납부, 모바일 앱 사용 패턴** 등으로 신용도를 보완 평가합니다.

### 3.1 TelecomPaymentRate (통신비 납부율)
- **설명**: 통신사 납부 이행률
- **데이터 타입**: Float
- **범위**: 0.0 ~ 1.0
- **단위**: 비율 (0 = 0%, 1 = 100%)
- **예시**: 0.95 (95% 이행), 0.75 (75% 이행)
- **비고**: 휴대폰, 인터넷 등 정기 납부 기록

### 3.2 UtilityPaymentRate (공과금 납부율)
- **설명**: 공과금(전기, 가스, 수도) 납부 이행률
- **데이터 타입**: Float
- **범위**: 0.0 ~ 1.0
- **단위**: 비율 (0 = 0%, 1 = 100%)
- **예시**: 0.98 (98% 이행), 0.85 (85% 이행)
- **비고**: 정기 고정비 납부의 규칙성과 신뢰도를 나타냄

### 3.3 SpendingConsistency (소비 일관성 점수)
- **설명**: 월별 소비 패턴의 일관성 점수
- **데이터 타입**: Float
- **범위**: 0.0 ~ 100.0
- **단위**: 점수 (높을수록 좋음)
- **예시**: 75.5 (중간), 82.0 (높음), 65.3 (낮음)
- **비고**: 월별 소비 변동성이 낮을수록 높은 점수 (생활의 안정성 표현)

### 3.4 RegularPaymentCount (정기결제 횟수)
- **설명**: 정기적인 거래(구독, 자동납부 등) 횟수
- **데이터 타입**: Integer
- **범위**: 0 ~ 20회/월
- **단위**: 횟수
- **예시**: 5 (주간 1회), 8, 12 (거의 매일)
- **비고**: 정기적인 소비 활동의 빈도 (높을수록 신뢰도 높음)

### 3.5 AppLoginFrequency (앱 로그인 빈도)
- **설명**: 금융 앱/서비스 접속 빈도
- **데이터 타입**: Integer
- **범위**: 0 ~ 35회/월
- **단위**: 횟수
- **예시**: 10 (주 2-3회), 15 (거의 매일), 20 (매우 활동적)
- **비고**: 금융 서비스에 대한 관심도와 활동성을 나타냄

## 4️⃣ 자동 계산 변수 (입력 불가)

### 4.1 is_thin_filer (씬파일러 판정)
- **설명**: 금융 기록이 거의 없는 고객 여부
- **데이터 타입**: Binary (0 또는 1)
- **결과**: 0 = 일반 고객, 1 = 씬파일러
- **용도**: 모델 입력 변수가 아니라 **평가용 집단 구분 레이블**
  (대안 데이터 포함/미포함 모델의 씬파일러 집단 AUC 향상 측정에 사용)
- **비고**: 코드에서 자동 판정하므로 대시보드에서 입력하지 않음
  (`src/data/simulator.py`의 `label_thin_filer()`)

#### 판정 기준 (둘 중 하나라도 만족) — 이슈 #15

| 기준 | 조건 | GMSC 해당자 |
|---|---|---|
| 기준 1 | 연체 관련 컬럼 3개 중 2개 이상 결측 | 0명 (0.00%) |
| 기준 2 | 아래 3가지를 **모두(AND)** 만족 | 약 4,110명 |
| | · `NumberOfOpenCreditLinesAndLoans` <= 1 (보유 대출·신용 한도 1개 이하) | |
| | · `NumberRealEstateLoansOrLines` == 0 (부동산 담보대출 없음) | |
| | · 연체 3개 컬럼이 모두 0 (연체 기록 없음) | |
| **최종** | 기준 1 OR 기준 2 | **약 4,110명** |

임계값은 `src/data/simulator.py` 상단 상수로 관리한다
(`MAX_OPEN_CREDIT_LINES`, `MAX_REAL_ESTATE_LOANS`). `None`을 넣으면 해당 조건을 사용하지 않는다.

#### 원본 기준을 그대로 쓰지 않은 이유

과제 용어집의 원본 정의는 「금융 연체 관련 컬럼 2개 이상 결측치이거나 **신용카드 거래 이력이
12개월 미만**인 고객」이다. Give Me Some Credit은 이미 대출을 보유한 금융 기록 보유자들의
데이터라 이 기준을 그대로 적용할 수 없다.

- **기준 1**: 연체 컬럼 3개에 결측이 하나도 없어 해당자 0명
- **기준 2**: 카드 사용 **기간(개월)** 정보가 데이터에 존재하지 않음

따라서 용어집의 상위 정의(「금융 이력이 부족하여 기존 CB 모델로는 적절한 신용평가가 어려운
개인」)에 맞춰, 데이터 안에서 **금융 기록이 가장 적은 사람**을 씬파일러로 정의했다.

#### 기준 2의 근거

**업계 관행**
Experian은 대출과 카드를 합친 활성 계좌가 1~2개이거나 5개 미만인 경우를 씬파일러로 분류한다.

**데이터 근거 1 — 계좌 수별 연체율 (부동산 담보대출·연체 기록이 없는 집단)**

| 보유 계좌 수 | 인원 | 연체율 |
|---|---|---|
| 0개 | 992명 | 13.00% |
| 1개 | 3,118명 | 5.32% |
| 2개 | 4,296명 | 2.93% |
| 3개 | 4,919명 | 2.70% |
| 4개 | 5,324명 | 2.01% |

0~1개 구간에서 연체율이 급격히 높고 2개부터 2~3%로 평평해진다. 계좌가 거의 없는 집단은
연체 이력이 없는데도 위험이 높게 나타나는, 즉 **기존 금융 정보로는 설명되지 않는 집단**이다.

**데이터 근거 2 — 연령 분포**
최종 씬파일러 집단의 35세 미만 비율은 **약 40%** (전체 13%)로, 사회초년생 비중이 높아
씬파일러 정의와 부합한다.

#### 한계 (리포트 명시 필요)

1. 기간이 아닌 **개수** 기준이므로, 카드 1개를 오래 사용해 온 사람도 씬파일러로 분류될 수 있다.
   원본 정의의 "거래 이력 12개월 미만"과 완전히 같은 집단은 아니다.

#### thin_filer_ratio 파라미터

`label_thin_filer(df, thin_filer_ratio=...)`에 값을 주면 목표 비율을 맞추기 위해
기준과 무관한 샘플을 **무작위로** 씬파일러로 표시하거나 해제한다. 이 경우 씬파일러 집단에
기록이 충분한 일반 고객이 섞여 AUC 향상 측정이 왜곡되므로, **평가에는 `None`(기본값)을
사용하고 기준대로만 판정한다.**

## 5️⃣ 모델 예측 대상

### 5.1 SeriousDlqin2yrs (목표 변수)
- **설명**: 2년 내 90일 이상 연체 여부 (신용도)
- **데이터 타입**: Binary
- **값**: 0 = 연체 없음 (정상), 1 = 90일 이상 연체 (부도)
- **클래스 분포**: 0 (93.32%), 1 (6.68%)
- **비고**: 모델의 예측 대상이므로 대시보드에서 입력하지 않음

## 6️⃣ 데이터 입력 시 유의사항

### 필수 확인 사항
1. **숫자형 입력**: 모든 값은 지정된 범위 내 유효한 숫자여야 합니다
2. **결측치 처리**: 
   - MonthlyIncome, NumberOfDependents는 선택적 입력 가능
   - 입력되지 않으면 전체 데이터의 중앙값으로 자동 보정됨
3. **스케일링**: 대시보드에서 입력한 원본 값은 모델 내부에서 자동으로 표준화됨

### 입력 순서 권장사항
1. 기본 정보: Age, NumberOfDependents
2. 신용 이력: RevolvingUtilizationOfUnsecuredLines, DebtRatio, MonthlyIncome
3. 연체 기록: 30~59일, 60~89일, 90일 이상 연체 횟수
4. 신용 계좌: NumberOfOpenCreditLinesAndLoans, NumberRealEstateLoansOrLines
5. 대안 데이터: TelecomPaymentRate, UtilityPaymentRate, SpendingConsistency, RegularPaymentCount, AppLoginFrequency
