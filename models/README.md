# models/ 산출물 설명

이 폴더에는 **최종 선택 모델 1개**와 그 모델을 쓰는 데 필요한 파일만 둡니다.
전체 18개 모델과 분할 데이터는 저장소에 올리지 않고, `main_step1.py` → `main_step2.py`로 다시 만들며 MLflow 서버에 기록합니다.

> **작성 규칙:** 파일이 바뀔 때마다 이 문서의 **맨 위에 새 항목을 추가**합니다.
> 기존 항목은 지우지 않습니다. 각 항목에는 날짜, 무엇이 바뀌었는지, 추가·삭제된 파일을 적습니다.

## 현재 파일 (최신 기준: 2026-10-13)

| 파일 | 역할 |
|---|---|
| `lightgbm_is_unbalance_integrated_v1.0.joblib` | **최종 모델** (통합 데이터 · LightGBM · is_unbalance) |
| `preprocess_scaler_v1.0.joblib` | 전처리 스케일러. 새 고객 입력을 같은 기준으로 맞출 때 사용 |
| `model_metadata.json` | 학습 조건, 9개 후보의 5-Fold 결과, 최종 선택 결과 |

### 최종 모델 성능
- 선택 기준: Validation AUC (9개 후보 중 최고)
- Validation AUC **0.9873**, Test AUC **0.9841**, Test KS **0.8781** (Test는 1회만 평가)

### 생성 조건
- 데이터 설정: `thin_filer_ratio=None`, `bias_ratio=0`
- 코드 기준: develop `6c83a72` (PR #64 머지 이후)
- 분할: train 105,000 / val 22,500 / test 22,500 (70:15:15, 계층 분할)

### 주의 (보고서에 반드시 적을 것)
- 대안 변수는 정답(연체 여부)과의 상관을 맞춰서 만들었습니다. 그래서 대안 데이터만 쓴 모델의 AUC도 0.97 수준으로 높게 나옵니다. 실제 데이터에서도 같은 수준이라는 뜻은 아닙니다. (이슈 #26 참고)
